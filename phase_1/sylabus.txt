2. Time Complexity
Subtopics
•	Complexity kya hai? 
•	Time Complexity 
•	Input size n 
•	Big-O notation 
•	O(1) 
•	O(n) 
•	O(n²) 
•	O(log n) 
•	Best case 
•	Worst case 
•	Average case 
Examples
console.log(arr[0]);
→ O(1)
for (let i = 0; i < n; i++) {
    console.log(i);
}
→ O(n)
Nested loop:
for (let i = 0; i < n; i++) {
    for (let j = 0; j < n; j++) {
        console.log(i, j);
    }
}
→ O(n²)

    console.log(i);
}

for (let j = 0; j < n; j++) {
    console.log(j);
}
